# Checkpoint módulo 5: blog modular

Esta versión organiza el blog por consola en un paquete `blog`. `main.py` inicia el menú; `datos.py` contiene los diccionarios y la lista de posts; `operaciones.py` lista, busca y filtra; `validaciones.py` verifica la estructura; `menu.py` controla la interacción.

Desde esta carpeta, ejecutar `python main.py`. Requiere Python 3.10 o posterior y no tiene dependencias externas. El menú permite listar posts, buscar por título, filtrar por etiqueta y validar los registros. La siguiente versión, en la raíz del repositorio, agrega clases y persistencia JSON.
